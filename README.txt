LayerAI standalone website prototype

This website is intentionally separate from the existing Hugging Face image-to-PSD app.
Do not replace or edit app.py or utils.py while previewing this site.

Files:
- index.html: homepage
- styles.css: design and responsive layout
- script.js: mobile navigation and footer year
- about.html: About page
- articles.html: starter educational articles
- contact.html: contact page (replace placeholder with a real email before public launch)
- privacy.html: privacy policy draft (must be customized before launch)
- terms.html: terms draft (must be reviewed before launch)

Preview:
Open index.html in a browser, or upload these files to a separate static hosting project.

Before public launch:
1. Replace placeholder contact information.
2. Review and customize privacy and terms pages to match actual practices.
3. Expand articles with your own tested examples and original images.
4. Confirm all navigation links and test on phone and desktop.
5. Keep the existing Hugging Face tool untouched until you explicitly decide to integrate it.

No backend, paid API, or connection to the existing image-to-PSD tool is included.
